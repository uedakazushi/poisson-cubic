# 一般の非可換 cubic threefold：内在的二次包絡と大域モジュライ — 研究方針

2026-11-03 / v3 — **研究再開時には最初に本ファイルを読む**

## 研究の中心対象と目標

中心的対象は、五つの次数１生成元を持つ Koszul ５次元 AS 正則代数 B と、中心正則三次直線 [G] による A=B/(G) から得る17次元の一般同型類である。既に構成した代数的な17係数正規形の generic 点を理解することを基盤とし、**(1) ambient 非可換 P⁴ を A から内在的に復元し、(2) 構造対象・シフト等を忘れた際に何が canonical に残るかを確定し、(3) Kuznetsov 成分と可換 cubic 側の幾何パラメータを対応させる**。

この個別目標は研究一般の方針変更原則とは別であり、新たな結果により柔軟に調整する。全ての非可換 cubic の分類、すべての境界点の正則性、compactification は当面の達成条件ではない。

## 主要な到達点と確実性

1. **証明済（一般論と既存原稿Gの結果）**：17次元量子中心三次対 A=B/(G) に対し、偏極付き三つ組 (qgr A,O,(1)) の section Z-algebra を取って quadratic envelope を形成すると B に一致する。理由は A₁=B₁, A₂=B₂ と B の二次性。三次核は CG であり、qgr A→qgr B の完全忠実な Abel 圏関手を与える。`paper_ja.tex` 命題「二次包絡による中心三次超曲面の復元」。この事項は既存原稿Gの§29にも証明されており、新規性は主張しない。
2. **今回紙面で直接証明**：一般混合族に対し、f₃=F|_{u=v=0} が滑らか、h≠0、S_h=B/(u,v) の中心が次数1,2で零、Gが中心正則とすれば Z(B)₂=Z(A)₂=Sym²⟨u,v⟩。Jacobi恒等式と平面三次式 f₃ の Hessian の非退化な定数方向を用いる。`paper_ja.tex` 補題「一般混合族の低次中心」。計算コードは有理数係数の確認に限り、一般証明は紙面。
3. **追加仮定付き・既存原稿G第33.1節の補題を適用**：qgr A に有限大域次元があり A が C[u,v] 上自由なら、Serre S=(-2)[3] から偶数 Veronese A^(2) を得て、その中心 conic D=C[u²,uv,v²] の二重被覆と二つの中央 chart の交わりから A 全体を復元できる。これは (D^b(qgr A),O) から ambient の同型類が決まることを示すが、O 自体の無標識な復元や Ku(A) からの復元ではない。`paper_ja.tex` 命題「構造対象と Serre 関手からの ambient の復元」。一般17係数族の generic tails 正則性の仮定の一括監査は未了。
4. **既存原稿Gに証明あり、今回全再監査はしていない**：中心対 incidence I113 は41次元、一般PGL5軌道24次元、次数付き代数同型類は17次元。genericな B は5次元 Koszul AS正則、A は中心三次商かつ degreewise flat。技術的基盤は `technical_core_ja.pdf` §§7–13, 28–33。
5. **独立した有理数体計算と幾何的正規化**：17係数の Hesse 正規形で、18次元の座標変換方向と17係数方向の35次元接行列が rank35。一般同型類への写像は dominant generically finite。`paper_ja.tex` §「17係数正規形」、`verify_17_slice.py`。有限多価の次数は未確定。
6. **従来の直接証明**：固定した smooth cubic X 上の Poisson スキームは Plücker cone Gr(2,5)。錐の頂点の２次近傍では flat 星積量子化を直接構成。Fermat 上に有限係数の中心三次商を構成。これらは generic 17次元モジュライの完成前提ではない。

## 解決すべき核心と優先度

**最優先 A — 内在的記述と標識の比較。** 一般17次元族で qgr A の generic smoothness（generic楕円境界の滑らかさと中心chartの仮定）を技術原稿G §§28,31と照合する。正則性が確認できれば、上記 Serre 由来の A^(2) の復元を無条件の generic 定理として整理する。O 自体の選択が非可換 cubic のカテゴリーから自然に決まるか、また Kuznetsov 成分と何らかの canonical marking を結び付けられるかを検討する。任意の導来同値で A を復元できるとは主張しない。

**優先 B — 幾何学的な17次元との対応。** T={(Y,Λ,ξ):Y⊂P⁴ smooth cubic, Λ≃P², Y∩Λ smooth, ξ∈Pic⁰(Y∩Λ)\{O}}/PGL5 と中心三次対の支配的な有限型対応を構成し、一般次数・自己同値の同一視を決定する。単なる次元一致は不十分。グルーイング圏の有限型実現と Ku(A)≃Ku(Y) の検証が本体である。

**優先 C — 判定法の一般化。** 任意の marked nc cubic を対象として、canonical Z-algebra の quadratic envelope が AS 正則か、中心三次１本で元の環に戻るかを検証する Koszul 5段複体・Frobenius 双対・noether 性の内在的判定を確立する。既に埋め込まれている族では結論が自明になることを踏まえ、この判定の価値は「ambient を前提としない nc cubic」にある。

**補助課題。** Poisson cone 全体への有限量子化、Plücker の2jetとの gauge 比較、17係数正規形の有限重複の次数。第一目標の前提にはしない。
